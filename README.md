# Three.js Car Playground

A browser-based driving sandbox built with Three.js and Cannon-es.

### 🚀 Live Demo

[Try it out on CodePen!](https://codepen.io/editor/xalaynax/pen/019ee621-eac4-7a19-bebd-ac68740f4412)

## Features

* Open-world driving
* Vehicle physics
* Interactive objects
* Tuning workshop
* Race track
* Stunt park
* Jump zone

## Controls

| Key     | Action        |
| ------- | ------------- |
| WASD    | Drive         |
| Shift   | Boost         |
| Space   | Jump          |
| H       | Honk          |
| R       | Reset Car     |

## Technologies

* Three.js
* Cannon-es
* HTML
* CSS
* JavaScript
