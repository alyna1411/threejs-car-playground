# Three.js Car Playground

A browser-based driving sandbox built with Three.js and Cannon-es.

## Features

* Open world driving
* Vehicle physics
* Interactives objects
* Tuning workshop
* Race track
* Stunt park
* Jump zone

## Controls

| Key     | Action        |
| ------- | ------------- |
| WASD    | Drive         |
| Shift   | Boost         |
| Space   | Jump          |
| H       | Honk          |
| R       | Reset Car     |

## Technologies

* Three.js
* Cannon-es
* HTML
* CSS
* JavaScript
